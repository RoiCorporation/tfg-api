# TFG API
API for my Bachelor's Thesis (TFG) project.



## ⚙️ Installation
1. Create a virtual environment if you still haven't.
```
python3 -m venv .venv
```

2. Activate the environment.
```
source .venv/bin/activate
```

3. Install all necessary dependencies.
```
pip install .
```



## 🚀 Run the app
To run the app locally, simply run ```fastapi dev```.
